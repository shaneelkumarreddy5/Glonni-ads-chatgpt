# Glonni Ads v0.1

Initial mobile-first rewards app prototype for Glonni Ads.

## Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Lucide React icons

## Local Commands

```bash
npm install
npm run dev
npm run lint
npm run type-check
npm run build
```

## Environment

Copy `.env.example` to `.env.local` when backend development starts.
Supabase keys are placeholders only in v0.1.
